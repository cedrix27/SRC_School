# SRC SCHOOL Flutter

Client enseignant mobile et client desktop admin/comptable. L’URL API se configure avec `--dart-define=API_URL=http://.../api/v1`. Les sessions utilisent `flutter_secure_storage`. Le SDK Flutter n’était pas installé dans l’environnement de développement au moment de la création ; `flutter pub get` et les builds restent à exécuter sur une machine équipée du SDK.
